# UI-002 — Non-modal reader panels trap Tab

- Classification: confirmed defect
- Severity: P2 Medium (keyboard users cannot leave docked panels)
- Confidence: confirmed
- Area: `src/components/FolioPanel`
- Affected format/platform: EPUB and PDF; desktop, keyboard users
- First observed: 2026-11-28 baseline audit
- Commit/build: `ed7a3a1`

## User impact
Appearance and In-book search are docked non-modal panels: the reader canvas
is supposed to stay visible and interactive. However, Tab cycles only inside
the panel, so a keyboard user cannot reach the dock or page canvas without
closing the panel first.

## Preconditions
Open any book; open Appearance or Ctrl+F search panel with the keyboard.

## Reproduction steps
1. Press `t`/`Ctrl+F`/open Appearance to focus a control inside the panel.
2. Press Tab repeatedly from the last focusable control in the panel.
3. Observe focus wraps to the panel's first control instead of moving to the
   reader controls outside.

## Expected
Non-modal panel lets Tab move out to the rest of the reader (it explicitly
opts out of the modal stack and scrim).

## Actual
`onKeyDown` traps Tab regardless of `modal`.

## Evidence
- `src/components/FolioPanel.tsx:39-52` — non-modal branch deliberately avoids
  modal-stack registration and focus steal.
- `:82-92` — `onKeyDown={(e) => trapTabKey(panelRef.current!, e.nativeEvent)}`
  is attached unconditionally; `aria-modal` is conditional but the trap is not.
- Non-modal consumers: `InBookSearchPanel.tsx:109`, `AppearancePanel.tsx:139`,
  `PdfAppearancePanel.tsx:84`.
- `tests/focusStability.test.tsx` / `tests/activePanel.test.tsx` do not cover
  Tab escape from a non-modal panel.

## Root cause
Focus-trap behavior was hoisted to the shared panel element without being
gated on `modal`.

## Proposed minimal fix
Attach `onKeyDown` only when `modal === true` (or early-return inside the
handler when `!modal`). Keep the document-level Escape handler for docked
panels. Consider a dedicated regression test for both modes.

## Regression test
Mount `FolioPanel modal={false}` with two focusable children, focus the last,
dispatch Tab, assert focus moves outside. Repeat with `modal` and assert wrap.
