# UI-013 — Single-select groups exposed independent pressed toggles

- Classification: design inconsistency
- Severity: P2 Medium
- Confidence: confirmed (RED test → GREEN)
- Area: `src/screens/SettingsScreen`, `src/screens/LibraryScreen`, `src/components/FolioRadioGroup`
- Commit/build: `ed7a3a1`

## User impact
Mutually exclusive settings and filters were rendered as independent `aria-pressed` buttons. Screen-reader users heard “toggle button, pressed” rather than a single-select group, and each option was a separate tab stop.

## Affected groups
Settings: App appearance, Interface zoom, High contrast, Language, Keep screen awake, Reopen last book, Default library view, Automatic backups, Restore mode. Library: Search scope, Kind filter.

## Evidence
- New assertion in `tests/settings.test.tsx` failed RED (`role="group"` + `aria-pressed`).
- `FolioRadioGroup.tsx` already provided correct semantics but was unused.

## Applied minimal fix
Replaced the hand-built `role="group"` + `FolioChip` groups with the existing `FolioRadioGroup` primitive (which renders the same chip styling with `role="radiogroup"`, `role="radio"`, `aria-checked`, roving tabindex and Arrow/Home/End keys). Boolean settings map to `"on"/"off"` values; Restore mode keeps its extra “reset confirmation” side effect; the mixed-purpose Library filter toolbar keeps its independent toggle chips while kind/search-scope are nested radio groups.

## Regression test
`tests/settings.test.tsx` asserts each static single-select group has `role="radiogroup"`, more than one `role="radio"`, and no `aria-pressed` child. Existing settings/axe tests still pass.

## Verification

- [ ] Native screen-reader check — not run (Linux host)

## Status / residual risk
**Fixed & verified (automated).** Untouched: the Library icon List/Grid view toggle still uses `aria-pressed` on icon buttons, and mixed toggle filters (status/tags/selection) legitimately remain pressed toggles. Restore mode is only rendered after a backup is selected, so its static presence was not asserted in the new test, but it was converted to the same primitive.
