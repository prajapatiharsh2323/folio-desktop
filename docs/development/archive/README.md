## Policy

- Preserve the original document; do not rewrite history.
- Add a header or closure note explaining why it was superseded and link the
  replacement.
- Update the original index to mark the record `superseded`.
- Archive only when the record is no longer the current source of truth. Git
  history alone is not a substitute for an explicit archive note.
