# Plans

- [`features/`](features/README.md) — feature intent/specification index. The
  detailed product specs remain in `.docs/`; do not duplicate them here.
- [`implementations/`](implementations/README.md) — implementation records and
  execution status for substantial changes.

Use a new record only for a distinct milestone or investigation. For small
changes, update the task board and, when useful, the current session record.

Naming:

- Implementation record: `I-YYYYMMDD-NN-<slug>.md`.
- Feature spec (only when `.docs/` has no suitable home):
  `F-YYYYMMDD-NN-<slug>.md`.
